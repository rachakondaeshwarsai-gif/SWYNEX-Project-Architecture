# SWYNEX Task 2 - Backend API and Database

This project implements a REST API for a Student Task Management System using Node.js, Express.js, and MySQL.

## Features
- Create tasks
- Retrieve all tasks and individual tasks
- Update existing tasks
- Delete tasks
- Validate task input
- Store task data in MySQL

## Technologies
- Node.js
- Express.js
- MySQL
- REST API

The backend source code, database schema, setup instructions, and API documentation will be maintained in this folder.
